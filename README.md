# Urban Fleet Intelligence

Enterprise Municipal GIS & Fleet Intelligence Platform for municipal transit corridors and infrastructure sensing.

## Core Capabilities

- **Overview (Command Center)**: Real-time municipal KPIs, active transit fleet monitoring, live detection feeds, corridor speed profile, and categorical event distribution.
- **Road Defects**: High-density pavement defect tracking (potholes, cracks, rutting, waterlogging) prioritized with multi-factor risk weighting.
- **Missing Infrastructure**: Expected vs. camera-detected infrastructure compliance auditing (zebra crossings, median dividers, speed limit signs, bus shelters).
- **Insights & Analytics**: AI-driven corridor congestion indexes, route occupancy matrix heat-grids, and ranked repair work order queues.
- **Safety Incidents**: Real-time traffic alerts, hit-and-run detection, ANPR license plate matches, bus camera footage requests, and emergency dispatch routing.

## Technology Stack

- React 19 + Vite
- Leaflet + React-Leaflet + Leaflet Heat + MarkerCluster
- Recharts + Framer Motion + Lucide Icons
- Tailwind CSS v4 + Vanilla CSS Design System (Inter font with tabular numbers)
